Runtime/security notes
----------------------
- Published widgets are still source-only. Legacy VWB1/VWB2 bytecode is not executed by V3; source is recompiled and verified locally.
- Incoming public-network bytes are validated by Kotlin before a typed WidgetHostEvent reaches the VM.
- network.accept acknowledges the exact event hash presented by the host.
- Incoming input handlers match exactly 1-2 locally declared input IDs.
- network.send/network text/invite creation remain tap-only to prevent receive-driven send loops.
- Text remains inert UTF-8, max 1 KiB/message, with the Session DHT retaining at most five text-message slots for a widget/session.
- State is bounded runtime-local state, not arbitrary device storage.
- Chess exercises matchmaking + acknowledged FROM/TO square flow, but does not yet implement legal chess-move validation or visual piece movement.
